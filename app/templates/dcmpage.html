DICOM Gateway v1.1
Swagger API Docs

Unified Endpoint: Proses SEMUA instance dari study dengan input yang fleksibel. Gunakan Study UID ATAU Accession Number (keduanya opsional untuk modifikasi).

Satu endpoint untuk semua skenario: Dengan/tanpa modifikasi tag, dengan Study UID atau Accession Number
* Masukkan Study UID jika Anda sudah mengetahuinya
* Sistem akan otomatis mencari Study UID dari Accession Number

Modifikasi Tag DICOM (Opsional):

Catatan: Endpoint ini akan memproses SEMUA instance dari study yang ditemukan. Jika tidak ada modifikasi, data akan di-relay murni seperti di PACS.

Upload file lokal, modifikasi, lalu kirim ke Router.

Upload file ke PACS (STOW-RS) dan hapus study by UID.
