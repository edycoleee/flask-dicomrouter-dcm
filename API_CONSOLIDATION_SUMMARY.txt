================================================================================
                         NEW UNIFIED ENDPOINT
================================================================================

Endpoint:
  POST /api/dicom/process

Input (at least one required):
  study: "1.2.3.4.5"                    // Study UID (optional)
  patientid: "P123"                     // Patient ID to modify (optional)
  accesionnum: "ACC20250001"            // Accession Number (optional)

Processing Logic:
  1. Determine Study UID:
     - If 'study' provided → validate it exists
     - If 'accesionnum' provided → lookup Study UID
     - At least one must be provided

  2. Get All Instances:
     - Fetch all series/SOP pairs from study
     - Process ALL instances (not just one)

  3. Loop Through Each Instance:
     - Download from PACS (WADO)
     - Modify DICOM tags (if patient_id or accesionnum provided)
     - Send to router (storescu)
     - Track success/failure

  4. Return Statistics:
     - Total instances found
     - Successfully sent
     - Failed instances
     - Modification details
