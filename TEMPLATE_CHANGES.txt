================================================================================
                      JAVASCRIPT CHANGES DETAIL
================================================================================

VALIDATION:
  Before: payload.study must be provided (required attribute)
  After:  At least ONE of study OR accessionLookup must be provided
          ✓ Both fields can be optional
          ✓ But at least one must have a value

PAYLOAD CONSTRUCTION:
  Before: payload = { study: val, patientid: val, accesionnum: val }
  After:  payload = { study: val, patientid: val, accesionnum: val }
          ✓ Undefined values removed before sending
          ✓ Prevents empty field pollution

RESPONSE HANDLING:
  Before: if (resp.ok) → only handles HTTP 200
  After:  if (resp.ok || resp.status === 207)
          ✓ HTTP 200: Full success (all instances sent)
          ✓ HTTP 207: Partial success (some instances failed)

STATISTICS DISPLAY:
  Before: Simple success/failure message only
  After:  "Total: 5, Terkirim: 3, Gagal: 2"
          + List individual failures with reasons

LOGGING:
  Before: [PROCESS], [RELAY], [RELAY-ACC] prefixes
  After:  [UNIFIED-PROCESS], [PARTIAL-SUCCESS], [STATS] prefixes
          ✓ Clearer indication of unified endpoint behavior
          ✓ Better diagnostic information
