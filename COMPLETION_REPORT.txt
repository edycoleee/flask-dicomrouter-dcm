================================================================================
                        LAYER DESCRIPTIONS
================================================================================

1. CORE LAYER (Infrastructure)
   Location: app/core/
   Purpose: Configuration and utilities shared across the application
   
   Files:
   • config.py - Environment variables, application initialization
   • logger.py - Logging configuration with rotating file handler
   
   Responsibilities:
   • Load and manage environment variables
   • Initialize application resources
   • Setup logging infrastructure
   
   Benefits:
   • Centralized configuration
   • Consistent logging across application
   • Easy to change configurations

2. SERVICES LAYER (Business Logic)
   Location: app/services/
   Purpose: Independent, reusable business logic
   
   Services:
   
   • PACSService (pacs_service.py)
     - get_dicom_metadata() - Fetch series/SOP UIDs
     - download_wado() - Download DICOM files
     - find_by_accession() - Search by accession number
   
   • DicomService (dicom_service.py)
     - modify_dicom() - Edit DICOM tags using dcmodify
     - send_to_router() - Send files via storescu
   
   • SatusehatService (satusehat_service.py)
     - fetch_token() - OAuth2 authentication
     - fhir_get() - FHIR API requests
     - get_imaging_study_id() - Get ImagingStudy from SatuSehat
   
   Characteristics:
   • Independent of each other
   • Testable in isolation
   • Reusable across different routes
   • Static methods for simplicity

3. ROUTES LAYER (Presentation)
   Location: app/routes/
   Purpose: HTTP API endpoints using Flask-RestX
   
   Endpoints:
   • POST /api/dicom/process - Process with optional modification
   • POST /api/dicom/upload - Upload and process file
   • GET /api/dicom/download/<id> - Download DICOM file
   • POST /api/dicom/direct-dcm - Direct relay by Study UID
   • POST /api/dicom/direct-dcm2 - Direct relay by Accession
   • GET /api/dicom/imageid/<acsn> - Get ImagingStudy ID
   
   Responsibilities:
   • HTTP request/response handling
   • Input validation
   • Service orchestration
   • Error handling
